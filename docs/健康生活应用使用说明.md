# 健康生活应用使用说明

“日日有益”是仓库内的独立个人健康网页，和夜班调度器使用不同端口、不同进程。手动记录不需要模型；只有用户主动提交文字或照片估算时，才会调用设置页选定的后端。

## 当前能做什么

- 保存身高、体重、目标体重、出生年份、活动等级和期望热量缺口。
- 估算 BMI、基础代谢、每日总消耗和保守的每日摄入目标。
- 手动记录饮食、运动消耗和体重，查看当天摄入、消耗、体重与预算余量。
- 输入一句中文或拍照/选图，得到食物、份量、热量区间和三大营养素候选；修改或删除后才入账。
- 在 mock、Claude Code、Codex 和 OpenAI 兼容接口之间切换估算后端。
- 查看近 7 天或 30 天摄入、运动、体重和记录明细，并生成 JSON 或 Markdown 存档。
- 把食材分成“绝不吃、不爱但能吃、可接受、喜欢”四档。
- 不联网地生成一份三餐草案；绝不吃的食材和分类会从模板中排除。

联网营养数据库和条码查询仍在后续阶段。模型结果只是待确认草稿；估算失败时仍可以手动输入。

## 配置

在数据目录的 `config.json` 增加：

```json
{
  "wellness": {
    "http": {
      "host": "127.0.0.1",
      "port": 8191
    }
  }
}
```

完整形状也可参考仓库的 `config.example.json`。不要把真实域名、口令或密钥写进仓库。

估算器设置不放在 `config.json` 或浏览器存储里，而是由设置页原子写入 `$NIGHTSHIFT_HOME/wellness/settings.json`。可选后端如下：

- `mock`：固定回放，可用于离线自测。
- `claude`：运行非交互 `claude -p`，可设置 model 和超时。
- `codex`：运行只读沙箱中的 `codex exec`，默认 model 为 `gpt-5.6-luna`。
- `openai_compatible`：设置 Chat Completions 兼容的 base URL、model、超时和 API key。

GET 设置接口永远不返回 API key，只返回 `has_api_key`。密钥框留空保留原密钥。“保留照片”默认关闭；关闭时压缩后的临时图会在估算结束后删除，开启后才会另存到 `wellness/photos/`。

## 启动

```bash
python3 -m nightshift wellness-serve
```

打开 `http://127.0.0.1:8191/health/`。健康数据写到 `$NIGHTSHIFT_HOME/wellness/`；没有设置 `NIGHTSHIFT_HOME` 时，沿用夜班的默认数据目录。

服务默认只监听本机，并且本身不提供登录页。若要挂到公网域名，必须让 nginx/Caddy 等反向代理提供 HTTPS 和访问鉴权，再代理到 `127.0.0.1:8191`；不要把监听地址直接改成 `0.0.0.0` 后裸露公网。

在终端中输出最近存档：

```bash
python3 -m nightshift wellness-report --days 7 --format md
python3 -m nightshift wellness-report --days 30 --end 2026-09-07 --format json
```

Markdown 可直接供人阅读或交给模型；JSON 与网页范围接口使用同一份按日聚合数据。对外的摄入和目标字段统一为 `calories_in` 和 `calorie_target`。

## 数据文件

- `profile.json`：个人档案与目标。
- `preferences.json`：食材偏好与硬约束。
- `entries/YYYY-MM-DD.json`：每天的饮食、运动和体重记录。
- `plans/YYYY-MM-DD.json`：当天生成的餐单。
- `settings.json`：估算后端与照片保留设置，可包含密钥，不应对外分发。
- `tmp/`：估算期间的压缩图片，请求结束后删除。
- `photos/`：只有开启“保留照片”时才写入。

写入使用文件锁和原子替换。若 JSON 损坏，服务会报错而不是静默清空。当前尚未提供网页导出/删除功能，备份或迁移时应先停服务，再整体复制 `wellness/` 目录。

## 安全说明

所有热量和代谢数字都是粗略估算，不替代医生或营养师。未成年人、孕哺期、慢性病患者、有进食障碍风险的人，或目标 BMI 偏低时，不应依赖自动热量缺口。程序遇到这些标记或异常目标会回退到维护热量并显示提醒。

照片会在本机压缩到长边不超过 1280 像素的 JPEG，上传上限 10 MB。选择 Claude、Codex 或兼容 API 时，文字、压缩图和有限的档案摘要会交给对应模型；请先确认其隐私政策和费用。
