提示词模板

占位符：{task} {title} {project_path} {context_limit} {worktree_instruction}（工作树任务渲染成"只在当前工作树施工、不要 commit"的前言，老式任务为空）

到线注入的话

占位符：{ctx_k} {limit_k} {handover_path} {commit_step}（工作树任务渲染为空，老式任务渲染成"把未提交的改动 commit；"）

五小时额度到线：暂停等刷新

占位符：{session_left} 剩余% · {session_line_left} 线（剩余%）· {resets_in} 几分钟后刷新 · {alarm_plan} 闹钟排法（系统自动填）

周额度到线：收尾交接

占位符：{week_left} 剩余% · {week_line_left} 线（剩余%）· {model_line_left} 单模型线（剩余%）· {model_note} 单模型周线说明 · {handover_path} · {commit_step}

别的模型周额度到线：只提示

占位符：{label} 模型名 · {left} 剩余% · {line_left} 线（剩余%）。本会话不停，只叫它别派那个模型的子 agent。

续班模板

占位符：{task} {shift} {handover} {title} {project_path} {context_limit} {worktree_instruction}（系统自动填，改文案别删花括号）

停后台指令

点任务卡上的「停后台」时敲进会话的话，原样发送、没有占位符。

疑似卡住自动中止后的自检提示

占位符：{stuck_minutes} 卡住的分钟数。Esc 只能打断当前这一轮，不会触发它自己收尾（Claude Code 官方说明：Stop 不认用户中断），所以按完 Esc 会紧接着把这段话敲进去起一个新轮次，让它自己判断刚才卡在哪、要不要继续。
